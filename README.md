# Handy Crafter

A crafting and shop game in the style of Path of Exile's item crafting. You're a village blacksmith: roll stat lines onto bases with Transmute, Chaos, Exalt, Divine and the rest, fill adventurers' orders, and grow your shop from Unknown to Legendary.

This repository only holds the playable builds. Grab the latest one below.

## Download the latest version

- **Windows:** [HandyCrafter-windows.zip](https://github.com/chriscentenera/handy-crafter-releases/releases/latest/download/HandyCrafter-windows.zip)
- **Android:** [HandyCrafter-android.apk](https://github.com/chriscentenera/handy-crafter-releases/releases/latest/download/HandyCrafter-android.apk)

These links always point to the newest release. Patch notes and older versions are on the [releases page](https://github.com/chriscentenera/handy-crafter-releases/releases).

## Install

**Windows**
1. Unzip the folder anywhere.
2. Run `HandyCrafter.exe`. There's nothing to install.
3. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. The game isn't code-signed.

**Android (7.0 or later)**
1. Download the `.apk` on your phone and open it.
2. Android asks once to allow installing apps from that source (your browser or file manager). Allow it, then tap **Install**.
3. New versions install over old ones and keep your save.

On a phone: tap a material to pick it up, then tap the item. Hold anything for details. The back button closes dialogs and opens the menu.
